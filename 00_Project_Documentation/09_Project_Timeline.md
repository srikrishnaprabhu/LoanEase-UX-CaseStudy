## Research Milestones

### Survey

- 42 responses collected.
- 41 valid responses analysed.
- One response excluded because consent was not provided.

### Interviews

- 12 semi-structured interviews completed.
- Qualitative thematic analysis completed.

### Research Report

A final research report was completed containing:

- Research methodology.
- Key findings.
- Design recommendations.
- Target users.
- Primary pain points.
- User needs.
- Design opportunities.
- Research limitations.
- Handover information.

## Repository Milestones

The project also underwent a Git/GitHub cleanup phase.

The public repository was subsequently reduced to intentional project documentation and research material.

Raw survey and interview response files were removed from public GitHub history and retained locally.

The main branch was synchronized with `origin/main`.
